# 🗄️ Data Cleaning and SQL Table Creation Project

## 📌 Project Overview

This project was completed as part of a **Data Analytics Internship** to demonstrate the fundamentals of **SQL database creation**, **data cleaning**, and **data preprocessing** using Python. The primary objective was to transform raw datasets into clean, structured, and analysis-ready data that can support accurate decision-making and future analytical tasks.

The project combines SQL for database management with Python in Jupyter Notebook for data preprocessing, showcasing a complete workflow from raw data to a well-structured dataset.

---

## 🎯 Objectives

* Create structured database tables using SQL.
* Import and inspect raw datasets.
* Clean and preprocess data for analysis.
* Handle missing values and duplicate records.
* Improve data quality for accurate analytics.
* Prepare datasets suitable for further analysis and visualization.

---

## 🛠️ Technologies Used

* Python
* SQL
* Jupyter Notebook

---

## 🚀 Project Workflow

### 1️⃣ SQL Table Creation

* Designed and created structured database tables using SQL.
* Organized data into a relational format for efficient storage and querying.
* Implemented SQL queries for database management.

---

### 2️⃣ Data Import

* Imported raw datasets into Jupyter Notebook.
* Explored dataset structure using Python.
* Examined data types and overall dataset quality.

---

### 3️⃣ Data Cleaning

* Identified and handled missing values.
* Removed duplicate records.
* Corrected inconsistent and invalid entries.
* Improved overall data consistency and reliability.

---

### 4️⃣ Data Preprocessing

* Prepared clean and structured datasets.
* Standardized data for analytical tasks.
* Enhanced dataset quality for downstream analysis and reporting.
