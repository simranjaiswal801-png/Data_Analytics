# Data Cleaning and SQL Table Creation Project

## Project Description

This project was completed as part of a Data Analytics Internship. The main objective of this project is to understand the process of database table creation using SQL and perform data cleaning and preprocessing using Python in Jupyter Notebook.

The project demonstrates how raw datasets can be transformed into clean, structured, and analysis-ready data through various preprocessing techniques.

---

## Project Overview

In this project, SQL was used to create structured database tables, while Python libraries in Jupyter Notebook were used for cleaning and preparing the dataset.

The workflow includes:
- Creating SQL tables
- Importing datasets
- Handling missing values
- Removing duplicate records
- Preparing clean and structured data for analysis

---

## Technologies Used

- Python
- SQL
- Jupyter Notebook

---

## Project Tasks

### 1. SQL Table Creation
- Created structured database tables using SQL queries
- Organized data into proper formats for storage and analysis

### 2. Data Importing
- Imported raw datasets into Jupyter Notebook
- Loaded and inspected the data structure

### 3. Data Cleaning
- Identified and handled missing values
- Removed duplicate records
- Corrected inconsistent data entries

### 4. Data Preprocessing
- Prepared clean and structured datasets
- Improved data quality for further analysis

---

## Key Learning Outcomes

- Understanding SQL table creation
- Practical experience with data cleaning techniques
- Dataset preprocessing using Python
- Preparing real-world data for analytics workflows

---

## Purpose of the Project

The purpose of this project is to gain practical knowledge of database management and data preprocessing techniques that are essential in the field of Data Analytics and Data Science.

---

## Conclusion

This project helped in understanding the importance of clean and structured data before performing analysis. It also provided hands-on experience with SQL database operations and Python-based data preprocessing techniques used in real-world analytics projects.
